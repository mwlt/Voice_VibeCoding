# Voice VibeCoding — WinUHid 虚拟键盘 安装说明

语音键唤醒豆包、千问等输入法需要 WinUHid 虚拟键盘驱动。SendInput 模拟按键会被输入法忽略，必须使用本包内的驱动与脚本。

## 推荐方式

1. 双击 **Run-Install.cmd**，UAC 点「是」
2. 观察窗口中的 `Phase: …` 行；出现 `Result: OK` 即成功
3. 若提示需重启，重启 Windows 后再双击 **Run-Status.cmd**（或重新打开应用，未就绪时会自动再修一次）
4. 未提示重启但设备仍不可用：再双击一次 **Run-Install.cmd**
5. 回到 Voice VibeCoding，确认状态栏「虚拟键盘」为就绪

## 已安装但仍需完整重装（测试/排查）

双击 **Run-Install-Force.cmd**，或在管理员 PowerShell 中：

```powershell
cd "本文件夹路径"
Set-ExecutionPolicy -Scope Process Bypass
.\install-winuhid.ps1 -Force
```

若设备一直 Stopped / 虚拟键盘装不上：旧脚本可能把 HardwareID 写成单字符（GitHub #10）。用 `-Force` 重装即可；脚本会自动检测并修复损坏的 HardwareID。

## 管理员 PowerShell 手动执行

```powershell
cd "本文件夹路径"
Set-ExecutionPolicy -Scope Process Bypass
.\install-winuhid.ps1
```

## 文件夹内容

- `WinUHid.dll`、`WinUHidPublisher.cer`
- `install-winuhid.ps1` — 安装脚本（含 Register→Bind→Scan 流程）
- `Run-Install.cmd` / `Run-Install-Force.cmd` / `Run-Status.cmd`
- `driver\WinUHidDriver.inf`、`.dll`、`.cat`

## 注意

- 必须使用本包内脚本，不要用上游 cgutman/WinUHid 原版替代
- 勿右键 ps1「使用 PowerShell 运行」；请用 Run-Install.cmd 或管理员 PowerShell
- 仍失败时请把 PowerShell 中全部 `Phase:` 行与应用日志一并反馈
