T1(蓝牙) Consumer（L0）说明 — 仅蓝牙产品
======================================
USB 路径（T1(USB)）不使用本包。见 docs/T1_USB_BLE_SPLIT.md。

不能只剥「搜索」一个键
--------------------
pnputil 只能禁用整块 Consumer Control HID。
整集禁用后：Home、删除、音量等会一起没反应。

要精确只挡 AC Search，需要签名过滤驱动（当前未做）。

现行策略
--------
- 保持 / 恢复 Consumer 启用 → Home、删除、音量可映射
- Windows 搜索由应用内 L1（键盘钩 + HotKey + Shell 钩）吞掉

自动修复
--------
若以前装过「整集禁用」：点设置页「自动修复 Consumer」或允许启动时的 UAC，
会重新 Enable T1 的 Consumer 集合。

命令行：
  .\install-t1-hid-filter.ps1 -Mode Status
  .\install-t1-hid-filter.ps1 -Mode Install
